## 설치 방법

1. Steam에서 원본 게임을 설치하고 게임을 완전히 종료합니다.
2. 다운로드한 ZIP을 빈 폴더에 **모두 압축 해제**합니다. 압축파일 안에서 실행하지 마세요.
3. `INSTALL.cmd`를 두 번 클릭합니다. Steam 등록 경로와 모든 등록 라이브러리에서 게임 설치 폴더를 자동으로 찾습니다. 중복 설치는 선택하며, 찾지 못하면 경로를 직접 입력합니다.
4. `Install completed. The game was not launched.`가 표시되면 설치가 완료된 것입니다.
5. 직접 게임을 실행한 뒤 언어에서 **한국어(기존 English 자리)**를 선택합니다.

Steam 업데이트 후 이전 패치 일부가 남은 상태도 인식합니다. 이전 백업은 새 Steam 원본과 해시가 같은 파일만 재사용하고 새 빌드용 원본 61개를 별도로 백업합니다. 이미 새 패치가 적용된 경우 반복 실행해도 다시 교체하지 않습니다.

설치 도구는 Steam이나 게임을 자동으로 실행하지 않습니다. 별도 Python·Unity·번역 플러그인 설치는 필요하지 않습니다.

### 자동 경로 탐색과 수동 경로 지정

INSTALL.cmd·RESTORE.cmd·VERIFY.cmd 모두 자동 탐색을 사용합니다. 특정 드라이브에 설치할 필요가 없습니다. 수동 지정이 필요하면 압축을 푼 폴더에서 PowerShell을 열고 다음 명령의 경로만 실제 게임 폴더로 바꾸세요.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Patch.ps1 -Mode Install -GamePath "게임 설치 폴더의 전체 경로"
```

이 옵션은 해당 실행에만 적용됩니다. 시스템 전체 실행 정책을 변경할 필요는 없습니다.

## 제거·원본 복원

게임을 종료한 뒤 `RESTORE.cmd`를 실행하면 자동 백업의 원본으로 복원합니다. 다른 게임 경로라면 위 명령의 `-Mode Install`을 `-Mode Restore`로 바꾸세요.

원본 자동 백업은 게임 폴더의 `.warota-ko-backup-26642447`에 저장됩니다. 복원에 필요하므로 보관하세요. 복원 후에도 백업은 남고, 세이브나 다른 모드는 삭제하지 않습니다.

`VERIFY.cmd`는 파일 상태만 검사합니다. `RESTORE.cmd`는 이 빌드의 원본 61개를 복원합니다.

Steam 빌드 또는 원본 파일 해시가 다르면 덮어쓰지 않고 중단합니다. 게임 업데이트나 다른 모드 때문일 수 있으니 강제로 적용하지 마세요. 설치·복원 도중 실패하면 이전 상태로 되돌리며, 롤백까지 실패하면 오류 메시지에 복구용 경로를 표시합니다.
